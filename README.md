# CodeAlpha Cybersecurity Internship — Task 2
## Phishing Awareness Training

### 📌 Project Overview

This project focuses on cybersecurity awareness and educating users about phishing attacks, their common techniques, warning signs, and prevention methods.

The goal is to help individuals recognize suspicious messages, identify potential online threats, and develop safer digital habits through an educational presentation and an interactive quiz.

### 🎯 Objectives

- Understand what phishing is and how it works.
- Identify different types of phishing attacks.
- Recognize suspicious emails, messages, and websites.
- Learn practical techniques to avoid phishing attempts.
- Improve awareness of online security and personal data protection.

A full video covering the topic:
  https://youtu.be/0jErjtMyXJY

### 📚 Topics Covered

**1. Introduction to Phishing**
- Definition of phishing.
- How phishing attacks manipulate users.
- Common goals of phishing attacks.

**2. Types of Phishing Attacks**
- Email Phishing
- Spear Phishing
- Smishing (SMS Phishing)
- Vishing (Voice Phishing)

**3. Warning Signs of Phishing**
- Suspicious sender addresses.
- Urgent or threatening messages.
- Unexpected attachments and links.
- Spelling and grammatical mistakes.
- Requests for passwords or sensitive information.

**4. Identifying Suspicious Websites**
- Checking website URLs and domains.
- Recognizing suspicious links.
- Avoiding unknown or untrusted websites.

**5. Phishing Prevention Techniques**
- Using strong and unique passwords.
- Enabling Multi-Factor Authentication (MFA).
- Verifying the sender before responding.
- Avoiding suspicious links and attachments.
- Reporting suspicious messages.
- Keeping software and security tools updated.

**6. Interactive Knowledge Assessment**
- A quiz designed to test understanding of phishing techniques, warning signs, and prevention strategies.

### 🛠️ Tools Used

- Canva — Presentation design and visual content creation.
- Voice-over and video-editing tools — Presentation narration and demonstration.

### 🎓 Learning Outcomes

Through this project, I developed a better understanding of:

- Common social engineering techniques.
- Different phishing attack methods.
- Identifying suspicious online communication.
- Practical cybersecurity awareness and prevention.
- Communicating cybersecurity concepts through educational content.

### 📂 Project Deliverable

An educational phishing awareness presentation covering the major concepts, supported by narration and an interactive quiz.

### ⚠️ Disclaimer

This project is developed for educational and cybersecurity awareness purposes only. It does not involve collecting credentials, targeting real users, or conducting phishing attacks.
